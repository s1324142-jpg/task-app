# Android 実機での受け入れ確認

自動テストは業務ロジックと通知ポートを検証する。OSが実際に通知すること、画面の表示、タップ操作は別途実機で確認する。

1. APKをインストールし、起動する。5タブが表示されること。
2. 空のホームから課題を追加。授業、課題名、日付・時刻を指定して保存する。
3. 課題詳細で日付と時刻、残り時間、授業、未着手が表示されること。
4. メモ、推定作業時間、重要度を編集し、作業中→完了→提出済み→未提出と変更する。
5. アプリを終了して再起動。保存した課題、設定、授業が維持されること。
6. 機内モードで課題一覧・詳細・今日やる・カレンダーを表示し、課題を編集できること。
7. 「今日やるに追加」で遠い締切の課題が今日やるに出ること。提出済みにすると消えること。
8. 月末・年末を含むカレンダーを移動し、該当日の締切数と詳細への遷移を確認する。
9. 一覧の4種類のソートと4種類のフィルターを確認する。
10. 課題URLを設定して端末ブラウザが開くこと。URLがない場合もクラッシュしないこと。
11. 設定から通知を許可する。Android 13以降ではOSダイアログを確認する。
12. 締切を現在から**3時間2分後**に設定し、「3時間前」をONにする。アプリをバックグラウンドにして約2分後の通知を確認する。OSによって遅延する場合は省電力設定も確認する。
13. 通知をタップすると該当の課題詳細が開くこと。アプリ終了中からも確認する。
14. 同じテスト用課題を通知前に提出済みに変更。旧時刻に通知されないこと。
15. 未提出に戻して新しい未来の締切を設定し、通知が再予約されること。
16. 締切を変更した場合に旧時刻で通知されず、新時刻で通知されること。
17. 課題削除・該当設定OFFの場合も旧予約が届かないこと。
18. 端末側で通知権限を拒否し、課題登録が可能でホーム・設定に案内が表示されること。再許可後、通知を再設定する。
19. 端末を再起動し、未提出の予約が維持されること。
20. 文字サイズを拡大した端末、小型端末、キーボード表示時に保存ボタンまでスクロールできること。

通知の精度はAndroidの省電力・メーカー実装に依存する。アプリの強制停止はOSが通知を止める場合があり、通常のバックグラウンド移行と区別して検証する。
